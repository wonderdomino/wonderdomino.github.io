Privacy Policy: What If Shorts Uploader

Last updated: November 23, 2026

What this app is

What If Shorts Uploader is a personal tool used only by the owner of the "What If" Shorts channel to upload the channel's own original videos to YouTube through the YouTube Data API v3. It is not offered to the public.

Google user data the app accesses

The app requests two permissions: https://www.googleapis.com/auth/youtube.upload, which lets it upload videos to the signed-in YouTube channel and set their title, description and privacy settings, and https://www.googleapis.com/auth/youtube.force-ssl, which it uses only to post the channel owner's own comment on the channel's own videos.

The app does not read, collect or store any other Google user data: no email address, contacts, viewing history, comments or analytics.

How the data is used

The access granted is used only to upload the channel owner's own videos and their titles, descriptions and settings to the owner's own YouTube channel, and to post the owner's comment on those videos.

Storage and sharing

The only thing stored is the OAuth sign-in token for the owner's channel, kept privately so uploads can run. No Google user data is sold, shared with third parties, or used for advertising.

Limited Use

What If Shorts Uploader's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

This app uses YouTube API Services. By using it you are agreeing to the YouTube Terms of Service. See the Google Privacy Policy.

Removing access

Access can be revoked at any time from the Google account's security settings: https://myaccount.google.com/permissions. After that the app can no longer upload, and the stored token stops working.
