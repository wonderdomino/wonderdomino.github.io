What If Shorts Uploader

What If Shorts Uploader is a personal tool used by the owner of the "What If" Shorts channel. It uploads the channel's own original short videos to YouTube using the YouTube Data API v3.

It is not a public service. Only the channel owner signs in, and the tool only uploads videos to the owner's own channel. It does not access, collect or store data about any other person.
